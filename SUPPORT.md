# Support & Community Help

## Getting Help

### 💬 Community & Discussion (Public)

- **GitHub Discussions:** Join discussions, ask questions, and share ideas on GitHub Discussions (`<repository-url>/discussions`).
- **GitHub Issues:**
  - [Report a Bug](./.github/ISSUE_TEMPLATE/bug_report.yml)
  - [Request a Feature](./.github/ISSUE_TEMPLATE/feature_request.yml)
  - [Documentation Improvement](./.github/ISSUE_TEMPLATE/doc_request.yml)

Before opening an issue or discussion, please search existing threads and consult [`docs/TROUBLESHOOTING.md`](./docs/TROUBLESHOOTING.md).

### 🛡️ Security Vulnerabilities

Do **not** open public GitHub issues or discussions for security vulnerabilities.
Follow our responsible disclosure procedure in [`SECURITY.md`](./SECURITY.md) or use [GitHub Private Vulnerability Reporting](https://github.com/hateem2121/RUN/security/advisories/new).
