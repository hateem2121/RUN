ELI5 Visual Architecture • Figure 6.0

Z-Index & Stacking Context Coordinate Map

How our webpage layers stack like transparent glass panes in a skyscraper, ensuring buttons, menus, cursors, and cards never collide.

COORDINATE HARMONY

Strict Stacking Invariant

Every element is assigned an intentional Z-index tier from theme.css. No arbitrary numbers (like z-[999]) are allowed, ensuring predictable layering.

CURSOR ISOLATION

Pointer-Events Invariant

The custom cursor floats at z-cursor (1600) with pointer-events: none so it never blocks clicks to links, dropdowns, or form inputs beneath it.

SCROLL SAFETY

Overflow Containment

Outer page container uses overflow-x-clip instead of overflow-x-hidden to allow sticky position elements like the Stats sidebar to remain anchored.
