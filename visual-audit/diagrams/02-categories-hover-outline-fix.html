Categories Ticker: Hover Font Outline Elimination vs High-Contrast Neon Outline

Diagnosing why category titles disappear under hover and providing the production fix that locks in a vibrant brand outline with offset preview follower.

❌ Root Cause in Code

// Categories.tsx:58
"stroke-text block text-display-xl font-bold uppercase",
"group-hover:text-foreground group-hover:[-webkit-text-stroke-width:0px]"

Setting text-stroke-width to 0px completely deletes the outline border, leaving a flat fill that easily washes out against the cursor backdrop.

✅ Remediated Implementation

// Categories.tsx (Remediated)
"stroke-text block text-display-xl font-bold uppercase",
"group-hover:[-webkit-text-stroke:2px_var(--color-primary)] group-hover:text-primary/10"

Maintains a bold 2px primary neon outline with a subtle translucent fill tint. The outline is never deleted and stays sharp in both dark and light modes.
