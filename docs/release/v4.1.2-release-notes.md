## 3. Remediation Matrix — What Changed in v4.1.2

### Tooling & Configuration Layer

- **F-01 (Tests):** Increased `hookTimeout: 60000` in `vitest.config.ts` to prevent integration suite timeout failures under heavy multi-file batch execution.
- **F-02 (Tooling):** Added `".agent/**"` to Knip ignore list in `knip.config.ts`, ensuring internal assistant tooling scripts are not flagged as unused workspace code.

### Shared Contracts Layer (`@run-remix/shared`)

- **F-03 (Shared Schemas):** Upgraded `shared/schemas/api/search.ts` from legacy `.nullable().optional()` chaining to idiomatic Zod v4 `.nullish()`, standardizing search input schemas across the monorepo.

### Server & Service Architecture Layer

- **F-04 (Server Services):** Refactored `server/services/product.service.ts` `listProducts()` from double-nested `new ResultAsync(async () => ...)` constructor to clean, direct `ResultAsync.fromPromise()`.
- **F-10 (Database Hygiene):** Dropped legacy orphaned `pgboss` schema tables in live Neon Serverless PostgreSQL (`lively-silence-31173468`), fully aligning database schema with Google Cloud Tasks + HTTP worker architecture.

### Client & User Interface Layer

- **F-05 (Client Root):** Pruned vestigial `SENTRY_*` environment keys and dead script tags from `client/app/root.tsx` loader.
- **F-06 (Client Routes):** Exported standard React Router v8 `meta` function returning document title and description in `client/app/routes/developer.tsx` (WCAG 2.4.2 Level A).
- **F-07 (Client Theme):** Migrated raw color classes (`bg-gray-100`, `border-gray-200`) in `client/app/routes/developer.tsx` to semantic Tailwind CSS v4 `@theme` design tokens (`bg-background-alt`, `border-border`).
- **F-08 (Client Reconciliation):** Replaced index-based list keys (`key={idx}`) with stable URL-based keys (`key={link.href}`) in `client/app/routes/developer.tsx`.
- **F-09 (Client Services):** Erased commented-out debug console logging blocks in `client/app/services/inquiry.server.ts`.
- **F-11 (Accessibility):** Added `tabIndex={0}`, `role="region"`, and accessible aria-labels to horizontal timeline scroll containers in `ProductionBlueprint.tsx` and `FactoryGallery.tsx` for Safari keyboard accessibility (WCAG 2.1.1).

